LES ISCLES WORKOUT — site web

Fichiers :
- index.html : contenu du site
- style.css : mise en page responsive pour téléphone et ordinateur
- script.js : menu mobile et éditeur local

Mise en ligne :
1. Dans le dépôt GitHub, ouvre le dépôt les-iscles-workout.
2. Pour chaque fichier existant (index.html et style.css), ouvre-le puis utilise le menu de modification pour le remplacer par le contenu du fichier correspondant de cette archive, ou supprime les anciens fichiers et téléverse ces trois fichiers à la racine du dépôt.
3. Assure-toi que index.html, style.css et script.js sont tous à la racine (pas à l'intérieur d'un sous-dossier).
4. Attends que GitHub Pages termine le déploiement.

Administration :
- Bouton « Administration » tout en bas du site.
- Code de démonstration : 1109.
- Important : cet éditeur stocke les changements dans le navigateur utilisé seulement. Les modifications ne sont PAS automatiquement publiées pour tous les visiteurs. Pour les publier, il faut modifier les fichiers du dépôt GitHub.
- Le code 1109 est présent dans le code public du site et ne constitue pas une vraie protection. Ne stockez pas de mot de passe ni de clé secrète dans les fichiers du site.
